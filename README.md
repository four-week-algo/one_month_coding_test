# four-week-algo

프로그래머스 코딩테스트 스터디 (2026.09.12 ~ 10.11)

## 현 진행상황을 공유합니다.
https://docs.google.com/spreadsheets/d/10E-Qe7dJqeLfdOhLltT3UHOskDmUHJBSqo5VugTMmco/edit?usp=sharing

## 일정

- **기간**: 9월 12일(토) ~ 10월 11일(일), 4주
- **주차 마감**: 매주 일요일 22:00
- **모의고사**: 매주 주말 1회, 총 5회

## 점수

| 항목          | 점수 |
| ------------- | ---- |
| Lv1           | 1점  |
| Lv2           | 2점  |
| Lv3           | 3점  |
| 모의고사 응시 | 4점  |

- **주간 목표: 12점**
- 예전에 푼 문제 재풀이도 인정 (커밋 메시지에 `[재풀이]` 표기)

## 모의고사

- 매주 토요일 오후1:00~2:30, **90분 연속** 응시
- 출제 당번이 **그 주 수요일까지** 문제 카톡에 공지 (당번은 자동 4점)
- 시작할 때 단톡에 방장이 알림 → 종료 후 결과 한 줄 공유 ex) [1회차] 1번 O / 2번 X / 3번 X

## 벌금

- 보증금 **30,000원** 선입금, 차감식 운영
- 주간 목표 미달 시 **1점당 1,000원** 차감
- 보증금 전액 차감 시 자동 하차
- 종료 시 잔액 반환, 차감된 금액은 완주자끼리 분배

## 커밋 규칙

- **자기 username 폴더에만** 커밋
- 파일명: `{문제이름}.{확장자}`
  - 예: `몫_구하기.java`
  - 재풀이는 `몫_구하기-2.java`
- 문제 풀이 위에 주석으로 문제링크 첨부

### 주의

- push 전 `git pull` 먼저
- 컴파일 결과물(`.class`, `.exe`, `a.out`)은 `.gitignore`로 제외됨
- 문제 지문 복사 금지, 링크만
- 언어별 보정 없음 (C++ / Java / Python)
